Resumo da lição

Um link leva a pessoa para outra página.

Ele é feito com a tag a. O endereço fica no atributo href.

<a href="contato.html">Contato</a>

Oi! Hoje vamos aprender a criar links.

Um link leva a pessoa para outra página. Para criar, usamos a tag a.

O endereço do destino fica dentro do atributo href. Por exemplo: href igual a contato ponto html.

O texto entre as tags é o que a pessoa clica. Escolha um texto que explique para onde o link vai.
